# ADR-0002: 首版身份、团队与项目授权

- 状态：Accepted; initial implementation and integration tests complete, hardening pending
- 日期：2026-10-09
- 决策依据：负责人确认的 DEC-P-08 至 DEC-P-10

## 背景

Web foundation 提供 Spring Boot、PostgreSQL/Flyway 和健康探针。首版需要在自托管服务中提供个人/团队身份、公开/私有项目及服务端角色授权。项目角色不得被解释为尚未实现的本体编辑 API。

## 决策

- 首版使用本地邮箱/密码和服务端会话；OIDC 留待独立评估。
- 自助注册关闭。平台管理员签发一次性邀请；受邀者通过有效邀请设置密码。首版不集成邮件服务，部署方须安全交付邀请 token。
- 空数据库由部署配置显式引导首位平台管理员；禁止默认凭证或匿名提权引导。成功引导路径已实现并由集成测试验证；失败与并发边界仍需测试。
- 团队角色为 Owner/Admin/Member；项目角色为 Owner/Admin/Editor/Viewer。
- 团队项目要求团队成员资格和显式项目成员资格同时成立。团队成员身份本身不继承项目权限。
- Owner/Admin 可管理项目元数据和成员；Viewer 只读。Editor 在身份/项目模块仅能读取元数据，本体写接口留待 ontology 模块。
- 公开项目允许匿名只读；私有项目要求显式项目成员。
- 所有对象级授权由服务端基于持久化关系执行；管理行为写入不含凭证的审计事件。
- 使用 Flyway 管理业务 schema；实体和接口实现放入当前 Spring 服务，不引入第二套后端或独立身份服务。

## 影响

- 需要 Spring Security、密码散列、CSRF、Flyway 业务迁移和 PostgreSQL API 集成测试。
- 邀请 token 交付不由应用自动发送；部署方承担安全传递职责。
- 首版会话采用服务端会话机制；session 共享/持久化、多实例部署策略需在支持多实例前另行决策。
- 未覆盖 MFA、密码找回、邮件验证、OIDC、团队删除、项目删除或本体文件操作。
- 项目 Owner/Admin 权限边界与团队 Admin 的项目创建权限必须由负向授权测试固定。

## 验收门槛

1. 空数据库只有提供显式管理员引导配置时才能启动并创建管理员；不得存在默认凭证。
2. 邀请 token 不以明文持久化，过期与重复接受均被拒绝。
3. 未认证用户不能读取私有项目或访问受保护 API；匿名只能读公开项目。
4. 团队成员但非项目成员不能读取团队私有项目。
5. 团队成员角色和项目成员角色分别执行确认的授权矩阵。
6. 缺失、伪造或跨资源 ID 的对象授权请求被拒绝；管理操作具有审计记录。
7. 数据库迁移、服务测试和工作区差异检查通过；环境受阻项明确记录。

## 后续评估

OIDC、密码恢复/MFA、持久化/共享会话、多实例部署、管理员邀请撤销、账户删除/数据保留策略、邮箱验证与完整威胁建模均需独立评审。本 ADR 不批准任何生产部署或外部身份提供方。

## 实施验证（2026-10-09）

- **VERIFIED:** Java 21 / Maven 3.9.16 的测试 suite 运行 5 tests，0 failures/errors/skips；覆盖基础 readiness、Flyway、邀请过期/重用拒绝和非管理员签发拒绝、token 摘要、密码散列、登录失败、会话登录/退出、CSRF、公开匿名只读、私有项目拒绝、团队成员显式项目成员要求及 Viewer/Member 拒绝管理操作、缺少 bootstrap 配置拒绝。
- **SOURCE-OBSERVED:** 首版 session 由 Servlet 容器内存维护，服务重启会使会话失效；没有分布式/持久化 session store。
- **UNVERIFIED:** 邀请过期边界、缺失 bootstrap 配置失败、登录限速、完整 Owner/Admin/Editor 操作组合、多副本会话行为及生产化运营约束。
