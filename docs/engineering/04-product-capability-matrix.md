## 状态定义

- **已实现且有运行证据**：有代码及可复现运行/测试证据。
- **源码存在但未验证**：有实现代码，尚无运行验证。
- **部分实现**：只有可核实子集。
- **未实现**：在审计范围内没有实现代码；不等同于证明所有外部系统都没有此功能。
- **暂不确定**：范围或证据不足以判断。
- **不属于当前 MVP**：明确决策排除；当前尚无已批准的 MVP，因此暂不使用此状态。

OpenProtégé 尚无完整产品业务能力。当前后端已具备经 PostgreSQL API 集成测试验证的本地身份/邀请、团队/项目元数据、部分角色授权，以及 RDF/XML/Turtle 文件导入、版本快照与导出首个切片；无 Web UI、桌面端或本体编辑器。500 MiB 上限下的资源性能、安全验收和格式保真仍未验证。Compose 应用容器在当前环境因数据库容器网络连接超时而退出。上游项目独立构建证据不计入 OpenProtégé 能力。

## 后续验收原则

拟纳入 MVP 的能力需先分配需求编号，再明确实际实现文件、正反向测试和验收数据。对本体文件处理应有导入—编辑—保存—导出—再次加载的往返证据；对 Web 权限应有跨项目越权读取/写入测试；对性能要求应先定义测试数据集、目标环境和测量方法。尚未批准的阈值不可预先填写。（PROPOSED）
