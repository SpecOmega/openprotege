## 用例边界

用例基于负责人确认的产品边界，而非现有功能。当前仓库没有可运行客户端或服务；以下均为待实现需求描述。角色权限的精确名称和矩阵仍 TBD。每项关联 [SRS](./SRS.md) 与 [验收标准](./acceptance-criteria.md)。

## UC-01 — 个人用户在桌面端本地编辑本体

- **参与者**：个人用户。
- **目标**：在不依赖实时 Web 同步的工作流中编辑本地 OWL 2 本体。
- **前置条件**：桌面编辑实现、支持格式和本地项目/文件模型已确定。（当前未满足）
- **主流程**：
  1. 用户在桌面端选择本地本体文件。
  2. 系统识别格式并解析；对受支持内容显示可理解的校验结果。
  3. 用户编辑本体内容并保存到明确的本地目标。
  4. 用户可导出文件并再次加载，以检查批准的语义保真规则。
- **失败/替代流程**：格式不支持、文件损坏或校验失败时，系统报告失败原因，不伪装为导入成功，也不覆盖用户文件。
- **关联需求**：OP-DESK-001、OP-ONT-001～006、OP-NFR-DATA-001。
- **验证状态**：未实现；需上游/技术 PoC 验证编辑、解析和保存行为。

## UC-02 — 团队管理 Web 项目

- **参与者**：团队成员、项目管理角色（名称待确认）。
- **目标**：在自托管 Web 环境管理项目、可见性和成员角色。
- **前置条件**：服务已部署，身份认证和角色矩阵已定义。（当前未满足）
- **主流程**：
  1. 用户通过获准的身份机制登录。
  2. 用户创建或打开一个 Web 项目。
  3. 经授权的管理者将项目设置为公开或私有，并配置成员角色。
  4. 系统在服务端按项目和角色对请求授权。
- **失败/替代流程**：未认证、角色不足或跨项目请求时，服务端拒绝；不能仅隐藏界面操作。
- **关联需求**：OP-PRJ-001～003、OP-WEB-001～004、OP-NFR-SEC-001。
- **验证状态**：未实现；身份、权限及自托管架构待决。

## UC-03 — 团队成员通过文件交换导入桌面修改

- **参与者**：有权访问项目的团队成员。
- **目标**：将桌面端编辑后的本体文件显式导入 Web 项目。
- **前置条件**：本地修改已保存为支持格式；用户对目标 Web 项目有写权限。
- **主流程**：
  1. 用户选择目标项目并发起文件导入。
  2. 系统校验用户权限、文件限制、格式和内容。
  3. 系统显示导入/验证结果；成功后按经批准的变更记录策略保存项目版本。
  4. 系统允许有权成员查看项目中已保存的内容。
- **失败/替代流程**：权限失败、超限、损坏、格式不支持或基线冲突时，拒绝写入并显示明确错误；原项目状态保持可识别。
- **关联需求**：OP-XCHG-001～004、OP-ONT-002～006、OP-WEB-003～005。
- **验证状态**：未实现；文件协议、冲突策略和服务端保存方案待 PoC。

## UC-04 — 成员导出本体供本地编辑

- **参与者**：有权读取 Web 项目的团队成员。
- **目标**：将 Web 项目中的本体导出至本地桌面端继续编辑。
- **前置条件**：目标用户具备读取权限；本体有可导出表示。
- **主流程**：
  1. 用户请求导出项目中的本体。
  2. 服务端校验项目访问权限，生成明确格式的文件。
  3. 用户在桌面端打开导出文件进行本地编辑。
  4. 后续回传通过 UC-03 的显式导入流程完成。
- **失败/替代流程**：未授权访问被拒绝；不支持的内容/格式须明确提示。
- **关联需求**：OP-XCHG-001、OP-WEB-003、OP-ONT-002～005。
- **验证状态**：未实现；公开/私有匿名导出语义和格式保真待确认。

## UC-05 — AI 提供候选建模建议

- **参与者**：有权操作项目的用户，可选 AI 功能。
- **目标**：查看候选本体建模建议，而不让 AI 静默修改项目。
- **前置条件**：AI 能力可选启用；用户有对应项目权限；输入和模型服务的数据政策已批准。（当前未满足）
- **主流程**：
  1. 用户主动提交请求或选择允许的上下文。
  2. 系统返回建议，并将其与持久化本体修改区分显示。
  3. 系统对候选结构执行定义的校验，向用户显示来源/限制。
  4. 用户拒绝建议，或检查后显式确认采纳。
  5. 仅经授权且确认后，系统才提交更改并记录必要审计信息。
- **失败/替代流程**：服务不可用时，核心编辑流程仍可用；校验失败、越权或用户未确认时不写入。
- **关联需求**：OP-AI-001～004、OP-AGT-001、OP-NFR-AI-001。
- **验证状态**：未实现；用户决策确认的是产品边界，不是 AI 能力或安全实现。

## UC-06 — 只读语义检索

- **参与者**：有权读取目标语料的用户。
- **目标**：按语义查找可访问项目中的本体信息，不修改本体。
- **前置条件**：检索能力和数据范围定义完成；用户具备读取权限。
- **主流程**：
  1. 用户提交查询。
  2. 系统只检索用户有权访问的内容。
  3. 系统返回只读结果及可追溯来源。
- **失败/替代流程**：无权访问的数据不出现在结果中；索引不可用时清楚报告，不能降级为越权访问。
- **关联需求**：OP-AI-003、OP-AI-004、OP-NFR-SEC-001。
- **验证状态**：未实现；索引、语义查询技术和权限过滤策略待技术验证。
